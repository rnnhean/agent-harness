## P1｜0.1 你将学到什么（4 分 14 秒）

讲师 Daniel Moka，15 年开发经验，医疗、油气、机器人、区块链、数字地图、ERP 都做过。现在专门给公司做 AI Agent：写代码的、做客服的、处理日常行政的。

**受众**：想把真实工作交给 AI Agent，并且敢信任它产出的软件工程师（p001 [00:24]）。

**承诺**：写十倍的代码，只花十分之一的精力评审（p001 [00:54]）。

**现状**：大多数人把 Agent 当聊天窗口用——问一句、等一会、自己检查、再问一句，一天都在重复这个循环。这么做放不大规模，**瓶颈是你自己**（p001 [00:54]）。

**课程要做的三件事**：

1. 让 Agent 自己用测试和护栏检查自己的工作
2. 让它自己跑，不需要人盯着
3. 只在需要人拍板的时候才叫人

**终点**：一个跑在自己服务器上的 AI 员工，7×24 小时工作。它用你积累的技能，从「第二大脑」里了解你的业务，每次改动都用测试证明。你从手机发任务，它夜里修 bug，早上按风险给 PR 排序，你先看危险的那几个（p001 [01:23]）。

**九个模块**：基础理论、harness、验证、评审、记忆、MCP、loop、AI 员工、复盘（p001 [01:51]–[03:38]）。

**每一讲的节奏**：先讲概念 → 在练习应用上演示 → 轮到你做（p001 [03:38]）。

**这一讲和本仓库的关系**：整门课的目标就是本仓库要做的东西。这里的 `box/` `hooks/` `mcp-server/` 是模块 1、2、6 的落地，其余模块见 README 的待办。
